# داشبورد فروش هایپرفامیلی ۱۴۰۵

این نسخه کاملاً استاتیک است و برای اجرای لوکال یا GitHub Pages به نصب و Build نیاز ندارد.

## اجرای لوکال

فایل `index.html` را در مرورگر باز کنید.

## انتشار روی GitHub Pages

محتویات پوشه `standalone` را در ریشه Repository قرار دهید و Pages را روی شاخه `main` فعال کنید.
